# Changelog

All notable changes to this project. Each entry links to its full per-version file in [changelog/](changelog/).

## [0.2.0](changelog/0.2.x/0.2.0.md) — 2026-10-02 · ⚠️ Breaking

BCP, STD, and FYI series resolve in iana_get_rfc_status, iana_get_registry_records looks up any column, and iana_search_registries ranks the closest titles first, singular and plural alike.

## [0.1.1](changelog/0.1.x/0.1.1.md) — 2026-10-01

First published release — ten read-only tools that look up IANA protocol registry entries, search and read any IANA registry, and report RFC and Internet-Draft status, all from keyless live sources.
