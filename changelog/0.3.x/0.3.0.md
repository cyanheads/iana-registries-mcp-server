# 0.3.0 — 2026-10-31

## Added

- Add the iana-registries-guide skill as a discoverable MCP resource.
- **Agent Plugins** root manifests support installation by compatible clients.

## Changed

- **Registry output** returns complete fields, notes, references, and metadata; records page by `limit` and cursor without a character budget ([#24](https://github.com/cyanheads/iana-registries-mcp-server/issues/24)). Media registration statements are returned whole after contact filtering.
- **Development tooling** syncs framework guides, packaging validation, bundle pruning, and the issue-report form; Docker uses Bun 1.4.3 → 1.4.4.

## Fixed

- **Registry value matching** distinguishes EtherType columns and supports scalar hex in decimal and established bare-hex columns ([#20](https://github.com/cyanheads/iana-registries-mcp-server/issues/20)).
- **Registry ranges** match signed integers, inclusive `a to b` ranges, strict open bounds, and width-preserving TLS byte pairs and wildcards ([#25](https://github.com/cyanheads/iana-registries-mcp-server/issues/25)).
- **Registry text** preserves paragraph boundaries and artwork spacing in both response surfaces ([#23](https://github.com/cyanheads/iana-registries-mcp-server/issues/23)).
- **Port and PEN searches** keep `found` true when matching assignments exist before an empty past-end page ([#22](https://github.com/cyanheads/iana-registries-mcp-server/issues/22)).
- **PEN markers** recognize reserved and unassigned entries case-insensitively ([#21](https://github.com/cyanheads/iana-registries-mcp-server/issues/21)).
- **PEN input** accepts snmpwalk OID spellings and returns targeted guidance for non-enterprise OIDs or a bare enterprise arc ([#27](https://github.com/cyanheads/iana-registries-mcp-server/issues/27)).
- **RFC status input** accepts bracketed citations, RFC DOIs, RFC Editor errata URLs, and section qualifiers with a document-level notice ([#28](https://github.com/cyanheads/iana-registries-mcp-server/issues/28)).
