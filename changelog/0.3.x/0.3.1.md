# 0.3.1 — 2026-11-21

## Added

- **IP block lookup** in `iana_get_registry_records` matches covering IPv4 and IPv6 blocks and pages the most specific matches first ([#26](https://github.com/cyanheads/iana-registries-mcp-server/issues/26)).
- **Registration templates** appear as clickable record references alongside the original `fields.file` path ([#33](https://github.com/cyanheads/iana-registries-mcp-server/issues/33)).

## Changed

- **Empty pointer tables** direct callers to the registries named in their notes, including curated PEN and BCP 47 lookups ([#32](https://github.com/cyanheads/iana-registries-mcp-server/issues/32)).
- **Value-only misses** can suggest a `contains` retry with per-column row counts for terms such as ALPN identifiers ([#34](https://github.com/cyanheads/iana-registries-mcp-server/issues/34)).
- **Bun minimum version** moves from 1.4.0 to 1.4.4.

## Fixed

- **Inline footnotes** render as bracketed anchors. Lookups accept the unfootnoted value and the previously returned spelling ([#29](https://github.com/cyanheads/iana-registries-mcp-server/issues/29)).
- **Repeated XML fields** match individual values while preserving joined display text, so a single character-set alias can locate a record ([#31](https://github.com/cyanheads/iana-registries-mcp-server/issues/31)).
