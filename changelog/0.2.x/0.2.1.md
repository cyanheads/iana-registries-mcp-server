# 0.2.1 — 2026-10-17

## Changed

- **Result limits** accept requests up to 1,000,000 and clamp to existing response caps, disclosing `requested_limit` and `effective_limit`. **RFC batches** accept up to 1,000 input items, deduplicate aliases, and continue ten distinct IDs per page through `ids_offset` with bounded previews. ([#17](https://github.com/cyanheads/iana-registries-mcp-server/issues/17))
- **Language extensions** report singleton allocation, defining RFCs, organization authority, and source freshness separately from base validity; unavailable metadata preserves completed tag analysis. ([#18](https://github.com/cyanheads/iana-registries-mcp-server/issues/18))
- **Distribution and development tooling** refresh registry launch metadata, bundle exclusions, container dependency pruning, framework guidance, and CodeQL analysis categories.

## Fixed

- **Decimal range lookup** matches exact integer bounds through the unsigned 64-bit domain, including CBOR registry ranges. ([#15](https://github.com/cyanheads/iana-registries-mcp-server/issues/15))
- **Canonical language tags** deduplicate preferred-value variant collisions and normalize the registered `heploc` context to `ja-Latn-alalc97`, preserving validity and unrelated parts. ([#16](https://github.com/cyanheads/iana-registries-mcp-server/issues/16))
