# 0.2.0 — 2026-10-02

Breaking: `rfc.see_also` is removed, BCP/STD/FYI ids return `kind: "series"` instead of `unsupported`, and an `iana_get_registry_records` `contains` cursor minted by 0.1.1 fails `cursor_mismatch`.

## Added

- **`iana_get_rfc_status` series** — `BCP 14` (or `bcp14`, `BCP-14`, `BCP0014`, or its rfc-editor.org/info/ or Datatracker URL) returns `kind: "series"` with ascending `series.members` and `series.datatracker_url`; a series with no member RFCs is `found: false` ([#6](https://github.com/cyanheads/iana-registries-mcp-server/issues/6)).
- **`rfc.is_also`** — the series an RFC belongs to, from one Datatracker membership read shared by every RFC in the call (one more planned request); when that read fails, `is_also` is left out and the notice names the RFCs ([#6](https://github.com/cyanheads/iana-registries-mcp-server/issues/6)).
- **`iana_get_rfc_status` id forms** — RFC and draft URLs on tools.ietf.org and ietf.org, Datatracker `/doc/id/` and RFC Editor inline-errata URLs, and file names (`rfc2616.txt`, `draft-ietf-httpbis-semantics-19.txt`); a URL's query and fragment are dropped before the length check ([#10](https://github.com/cyanheads/iana-registries-mcp-server/issues/10)).
- **Draft revision past the latest** — stays `found: true` with `guidance` naming the latest revision ([#10](https://github.com/cyanheads/iana-registries-mcp-server/issues/10)).
- **`failed[].retryable`** on `iana_get_rfc_status` — `true` for `request_limit`, `false` for a refused redirect or a body over its ceiling, absent when the failure states neither ([#13](https://github.com/cyanheads/iana-registries-mcp-server/issues/13)).
- **`iana_get_registry_records` `field`** — `value` matches the named column (case-insensitive) instead of `value_field`; an unknown column fails `unknown_field`, and `field` without `value` is ignored with a notice ([#9](https://github.com/cyanheads/iana-registries-mcp-server/issues/9)).
- **`registry_notes`** — the first page of a sub-registry read carries the registry root's notes and footnotes, sharing the 25-note, 4,000-character budget with `notes`, table notes first ([#8](https://github.com/cyanheads/iana-registries-mcp-server/issues/8)).
- **Nested tables** — a table that nests tables lists its direct children in `subregistries` on its first page, beside its records; a record-less one's notice says to pass one of the listed ids ([#8](https://github.com/cyanheads/iana-registries-mcp-server/issues/8)).
- **`offset`** on `iana_get_registry_records` pages after the first: the matching records before the page ([#9](https://github.com/cyanheads/iana-registries-mcp-server/issues/9)).
- **Public hosted endpoint** — `https://iana-registries.caseyjhand.com/mcp` (Streamable HTTP, no key) is listed as a `server.json` remote, with client setup in the README.
- **`template.available`** on `iana_lookup_media_type` — `false`, with a notice that the references are the defining documents, when IANA serves its "No registration template available." page for the type (`image/gif`, `text/plain`) ([#12](https://github.com/cyanheads/iana-registries-mcp-server/issues/12)).

## Changed

- **`iana_get_registry_records` keys** — every row is keyed by `value_field`; a row without that cell omits `records[].value` and never matches a key lookup, and a `value` miss names the other columns holding the value ([#9](https://github.com/cyanheads/iana-registries-mcp-server/issues/9)).
- **Numeric and hex `value` matching** — digits compare by number (`0443` finds `443`); one `0x` token compares by number and matches `0xA-0xB` range rows; other `0x` forms (`0x1301`, `{0x13,0x01}`, `0x13 0x01`) compare their digits as written ([#9](https://github.com/cyanheads/iana-registries-mcp-server/issues/9)).
- **Ranked `contains`** — records with a field equal to the words come first, and the cursor pages that ranked list ([#9](https://github.com/cyanheads/iana-registries-mcp-server/issues/9)).
- **Listing responses** — `value`, `contains`, or `field` given without a sub-registry are reported as not applied instead of dropped silently ([#9](https://github.com/cyanheads/iana-registries-mcp-server/issues/9)).
- **`iana_lookup_media_type` keyword notices** — a one-word keyword shaped like a file extension (`jpg`, `.mp3`) that names no registered top-level type or subtype gets a notice that keyword search reads type names, never extensions; a one-word miss no longer says "Try fewer words" ([#11](https://github.com/cyanheads/iana-registries-mcp-server/issues/11)).
- **`source.url`** — names the URL that answered, the last hop when a registry URL redirects ([#13](https://github.com/cyanheads/iana-registries-mcp-server/issues/13)).
- **Descriptions and server instructions** — the search example is "protocol numbers"; the RFC tool names series; the media tool says keyword never matches file extensions.

## Removed

- **`rfc.see_also`** and its "See also" line — the relayed RFC Editor field was always empty; `is_also` replaces it ([#6](https://github.com/cyanheads/iana-registries-mcp-server/issues/6)).

## Fixed

- **`iana_search_registries` ranking** — query and index tokens fold singular and plural (`ethertype` finds "Ethertypes"), and results rank by exact id (a registry id given as words included), title closeness, missing words, then index position ([#7](https://github.com/cyanheads/iana-registries-mcp-server/issues/7)).
- **Duplicate index entries** — a registry/sub-registry pair listed under several categories comes back once, its categories joined with `"; "` ([#7](https://github.com/cyanheads/iana-registries-mcp-server/issues/7)).
- **Redirects** — the client follows them itself: a target on iana.org, rfc-editor.org, or datatracker.ietf.org is requested over https, never plain http; any other target, a URL with credentials or a non-default port, or a sixth redirect fails at once with `retryable: false` ([#13](https://github.com/cyanheads/iana-registries-mcp-server/issues/13)).
- **First-answer failures** — a wrong content type and a body over its byte ceiling fail on the first answer instead of after three attempts; only the over-ceiling failure is `retryable: false` ([#13](https://github.com/cyanheads/iana-registries-mcp-server/issues/13)).
- **Paged Datatracker answers** — a `relateddocument` page with more pages after it is unreadable instead of a short edge list ([#6](https://github.com/cyanheads/iana-registries-mcp-server/issues/6)).

## Dependencies
